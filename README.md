# NOCEyes Agent Hub

A lightweight, dependency-free web application designed to help the AIOps team understand and analyze Parsed Alert Data generated by NOCEyes.

## Overview

When an alert is triggered in NOCEyes, the platform may return a **Parsed Data JSON** containing information extracted from the original monitoring alert.

Although this parsed data contains useful information, understanding the structure and meaning of the data can sometimes be difficult, especially when the JSON contains a large number of fields or monitoring-specific values.

**NOCEyes Agent Hub** was created to make this process easier.

The application provides a collection of small, focused agents that take Parsed Alert Data as input and transform it into a more readable and meaningful representation.

Instead of manually inspecting a large JSON payload, an AIOps engineer can paste the Parsed Data into the appropriate agent and quickly identify important information such as:

- What alert occurred?
- Which device or host was affected?
- What entities are involved?
- What is the severity?
- Is the alert active?
- What is the current status?
- Which related alerts are present?
- What additional information is available in the parsed payload?

The goal is to make Parsed Alert Data easier to understand during alert investigation and operational analysis.
